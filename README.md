# Quiz App
Interactive Multiple‑Choice Quiz — HTML • CSS • JavaScript  
Live Demo: https://lavinia-81.github.io/Quiz-App/

A lightweight, responsive quiz application built using vanilla JavaScript, HTML, and CSS.
This project demonstrates core front‑end concepts such as DOM manipulation, event handling, timers, dynamic UI updates, and state management.

---

## Overview
Quiz‑App allows users to answer multiple‑choice questions, track their score, and progress through the quiz using a clean and intuitive interface.
The project was created early in my learning journey to explore how JavaScript can be used to build interactive browser applications without external libraries.

---

## Features
### Core Functionality
- Start quiz with a dedicated Start button
- Display questions and multiple‑choice answers
- Navigate through questions using a Next button
- Show final score at the end of the quiz
- Timer for each question
- Dynamic UI updates based on user selections

### UI & Design
- Clean and responsive layout
- CSS‑based styling
- Visual feedback for selected answers

### JavaScript Logic
- Question rendering
- Answer validation
- Score tracking
- Timer countdown per question
- State management for quiz progress

## How to Use
- Open index.html in your browser.
- Click Start to begin the quiz.
- Select an answer from the multiple‑choice options.
- Click Next to move to the next question.
- At the end, your score will be displayed.
- The timer will count down for each question — answer before time runs out.
